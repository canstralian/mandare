# v0.3.0

> **Status: `0.3.0rc1` (release candidate).** This is a pre-release for
> validation. Highlights below shipped across commits since v0.2.2; per the
> repo's convention the release PR itself only carries the version bump and
> these notes.

## Highlights

- **Control-plane authentication (H1 security item, closes #39).** Mutable
  control-plane routes now require an `X-API-Key` checked against the
  comma-separated `RIF_CONTROL_PLANE_API_KEYS` env var, using SHA-256 digests
  and `hmac.compare_digest` (constant-time, no length-mismatch 500s). **Fails
  closed:** with no keys configured, guarded routes return `503` rather than
  allowing through. Guarded: `POST /v1/environment/{name}`,
  `POST /v1/policy/evaluate`, `POST /v1/posture/{posture}`,
  `POST /v1/posture/reset`, `PUT`/`DELETE /v1/policies/{rule_id}`, and
  `POST /v1/mcp/metasploit/token`. Read-only summary routes stay open.
- **Simulation routes are now genuinely side-effect-free.** The unauthenticated
  `POST /v1/mcp/invoke` and `POST /v1/mcp/metasploit/evaluate` run as dry-runs
  (`record=False`): they compute and return a decision without mutating posture
  or writing to the JSONL decision/evidence stores. An anonymous caller can no
  longer force posture to `locked` (a control-plane DoS) or flood the audit log.
  The authenticated `POST /v1/policy/evaluate` remains the recording path.
- **Fix: `POST /v1/posture/reset` route no longer shadowed** by the
  `POST /v1/posture/{posture}` path-param route, which had captured `reset` as a
  `Posture` value and returned `422` (#44).
- **CI reproducibility: ruff pinned to `0.15.22`** across both workflows and the
  `[dev]` extra. Unpinned installs had begun pulling ruff 0.16.0, whose changed
  import-sorting/lint defaults turned `main` red with no code change (#47).
- **Dev environment & docs:** `AGENTS.md` Cursor Cloud setup notes (#37, #43),
  and ADR-0008 (AgentOS/RIF v1 governed runtime architecture, #33).

## Upgrade notes

- **Set `RIF_CONTROL_PLANE_API_KEYS` before deploying.** Until it is configured,
  every guarded control-plane route returns `503` by design — nobody ships with
  control-plane auth silently disabled. Callers of guarded routes must send
  `X-API-Key`.
