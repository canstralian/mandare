# v0.2.2

> Features below shipped across commits since v0.2.1 and are documented
> retroactively here. This release PR (PR #23) itself only contains the
> version bump, changelog, and versioning infrastructure changes.

## Highlights
- Explainability model for policy decisions (request/decision-aware)
- Cryptographic security utilities, including a tamper-evident audit chain
- CodeQL, Bandit, dependency, and quality scanning workflows
- Release automation workflow (build + publish on tag push)
- Repo governance: CODEOWNERS, Dependabot, SECURITY.md, CONTRIBUTING.md,
  governance-aware PR template, MIT license
- PolicyStore custom rules wired into PolicyEngine (#9)
- CLAUDE.md added with architecture, workflow, and convention docs
- `__version__` now derived from installed package metadata via
  `importlib.metadata.version()` — eliminates version drift between
  `pyproject.toml` and `__init__.py`; version consistency enforced by
  `tests/test_version.py` on every CI run

## Validation
- Ruff clean
- Mypy clean
- Tests passing
