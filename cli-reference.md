# CLI Reference

## Binary

```bash
rif
```

## Execute

```bash
rif execute --intent "hello"
```

## Replay

```bash
rif replay exec_123
```

## Evidence

```bash
rif evidence export exec_123 bundle.zip
```

## Telemetry

```bash
rif telemetry tail
```

## Validate

```bash
rif validate config runtime.yaml
```

## Policy

```bash
rif policy check request.json
```

- --config
- --json
- --verbose
