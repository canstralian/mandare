# Support

Mandare is an actively developed open-source project. Support is primarily community- and repository-based rather than an SLA-backed service.

## Where to ask

- **Bug or reproducible behaviour:** open a GitHub issue using the Bug Report template.
- **Feature/design discussion:** use a Feature Request or discussion appropriate to the repository's enabled GitHub features.
- **Security vulnerability:** do **not** use a public issue. Follow [`SECURITY.md`](SECURITY.md).
- **Contributor questions:** start with [`CONTRIBUTING.md`](CONTRIBUTING.md), [`DEVELOPMENT.md`](DEVELOPMENT.md), and [`docs/README.md`](docs/README.md).

## Before opening an issue

Please include:

- the exact Mandare version or commit;
- Python version and operating environment;
- the smallest useful reproduction;
- relevant configuration (with secrets removed);
- expected versus observed behaviour;
- relevant test or log output.

## Support expectations

This project does not currently publish a response-time SLA, uptime commitment, or paid support agreement. Do not treat repository issue activity as a contractual support service.

## Security and sensitive data

Never paste credentials, API keys, tokens, private customer data, or undisclosed vulnerability details into public issues or pull requests.
