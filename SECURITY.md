# Security Policy

## Supported Versions

Only the latest tagged release is supported.

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities.

Report suspected security issues privately through GitHub Security Advisories:
https://github.com/canstralian/rif-runtime/security/advisories/new

## Scope

Relevant issues include:

- policy bypass
- incorrect allow/deny decisions
- replay or audit corruption
- unsafe MCP/tool invocation paths
- secret leakage
- dependency vulnerabilities
